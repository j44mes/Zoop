# Visual direction

Precision Workspace and Editorial Intelligence, used together.

The canvas is a warm neutral (`#f6f3ee`). Cards are off-white. Text is near-black. One blue (`#1f4fd8`) marks the current action and focus. Poor, ok, and good keep a tint plus a word, so colour is not the only status.

Type stays at 14px or larger. Spacing uses 4, 8, 12, 16, 24, and 32 pixels. Motion is limited to the audit bar and is removed when `prefers-reduced-motion` is set.

Styles apply only under `.seostudio-dashboard` and `.seostudio-panel`.
